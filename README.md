📊 Data Analyzer and Transformer

A beginner-friendly Python project that allows users to input, analyze, filter, sort, and transform numerical data using different Python concepts. 🐍

📌 About the Project

Data Analyzer and Transformer is a console-based program designed to work with a dataset of integers.

The program provides several options to analyze the data, including calculating the minimum, maximum, sum, and average. It also demonstrates concepts such as 
recursion, lambda functions, sorting, keyword arguments, and functions.

✨ Features

•	⌨️ Input a dataset of integers

•	📊 Display basic data summary

•	🔢 Calculate factorial using recursion

•	🔍 Filter data using a threshold

•	🔄 Sort data in ascending or descending order

•	📈 Display dataset statistics

•	🧮 Calculate minimum, maximum, sum, and average

•	📋 Menu-based interface

•	🌱 Beginner-friendly implementation

🔧 Main Functions

⌨️ input_data()

Takes integers from the user and stores them in the dataset.

📊 summary()

Displays:

•	Total number of elements

•	Minimum value

•	Maximum value

•	Sum

•	Average

🔢 factorial(n)

Calculates the factorial of a number using recursion.

For example:

5! = 5 × 4 × 3 × 2 × 1 = 120

🔍 filter_data()

Uses a lambda function and filter() to display values greater than or equal to a user-provided threshold.

🔄 sort_data()

Allows the user to sort the dataset:

•	Ascending

•	Descending

📈 statistics(**kwargs)

Receives dataset statistics using keyword arguments and returns the minimum, maximum, sum, and average values.

🛠️ Requirements

🐍 Python 3.x

No external libraries are required.

▶️ How to Run

1.	Install Python 3 if it is not already installed.

2.	Download or clone this repository.

3.	Open the project folder in a terminal.

4.	Run the Python file:

python data_analyzer.py

Or, on some systems:

python3 data_analyzer.py
